# تطبيق Windows

المجلد الحالي يجهّز المشروع ليصبح تطبيق Windows، لكن نسخة Electron لم تُربط بعد عمداً حتى نثبت الموقع أولاً.

الخطوة التالية بعد اختبار الموقع:
1. إضافة Electron وملف main process.
2. بناء تطبيق Windows installer.
3. في نسخة الإنتاج، يتصل التطبيق بـ API عبر HTTPS ولا يشغّل السيرفرات محلياً بصلاحيات مرتفعة.
