# قائمة ما يلزم قبل إطلاق استضافة عامة

- [ ] تسجيل مستخدمين مع تحقق البريد وإعادة تعيين كلمة المرور.
- [ ] قاعدة بيانات للمستخدمين والسيرفرات والخطط.
- [ ] API يتحقق من ملكية السيرفر قبل كل إجراء.
- [ ] عامل تشغيل منفصل يعمل على Linux.
- [ ] تشغيل كل سيرفر داخل container بحدود CPU وRAM ومساحة القرص والشبكة.
- [ ] منع الوصول إلى Docker socket من التطبيق العام.
- [ ] تنزيل ملفات السيرفر من مصادر موثوقة والتحقق من النسخ.
- [ ] سياسات إساءة الاستخدام ومعدل الطلبات وسجلات تدقيق.
- [ ] نسخ احتياطية واختبار استرجاع.
- [ ] TLS وقياس الموارد والتنبيهات.
- [ ] نظام اشتراكات عبر مزود دفع متاح قانونياً؛ لا تخزّن بيانات البطاقات بنفسك.
- [ ] اختبار أمني قبل السماح للناس بالتسجيل.
